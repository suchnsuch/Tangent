The Page Lens presents a note's content in place of the Folder, [[Queries|Query]], or other [[Sets|Set]] that is currently selected. It can let you treat a folder as though it were a document with nested children. It is excellent for "Maps of Content" or any other situation where you want to create a landing page for a collection of notes.

The "Page Path" setting lets you choose the note that will be displayed. The path is stored as a relative path from the Set. You need not use a note inside the Set!

By default, the Page Lens will first look for a child note with the same name as the Set. If that is not found, it will look for an `index.md` note child.
