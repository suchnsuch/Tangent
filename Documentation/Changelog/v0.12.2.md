New since v0.12.1:
+ Added multiple [[Embedding]] improvements:
	- Embed link on their own line now collapse the text, removing the empty gap. // This can be disabled in settings.
	- Added support for [[#Floating Embeds|floating]] embedded images, videos, etc to the left or right.
	- Added support for controlling the width & height of all embedded content.
+ Some RTL language improvements:
	- Fixed an issue where headers in RTL languages did not work correctly.
	- Added support for treating `+` as the equivalent to `x` for completing [[Todos]], allowing RTL language detection to not get tripped up. // [PR 386](https://github.com/suchnsuch/Tangent/pull/386)
	- Fixed an issue where the [[Cards Lens]] did not correctly render RTL languages. // Thanks to [PR-381](https://github.com/suchnsuch/Tangent/pull/381#issuecomment-4655400926) for finding the cause of this one.
+ Added unicode replacement support for ⟹⇒double arrows⇐⟸ ([PR 376](https://github.com/suchnsuch/Tangent/pull/376))
+ Added a [[Database#Startup Behavior]] option that lets you choose between restoring old windows or always showing the workspace selector. // [PR 385](https://github.com/suchnsuch/Tangent/pull/385)

- Fixed a leak where links in closed notes retained their node handles on their target files and folders leaked node handles. // [Issue 361](https://github.com/suchnsuch/Tangent/issues/361)
- Fixed an Embedded PDF scaling issue unique to Windows 10. // [PR 383](https://github.com/suchnsuch/Tangent/pull/383)
- Fixed an issue where [[Wiki Links]] could not link to notes with brackets in their name.
- Fixed an issue where raw links auto-embedded in sub-lists but not in top-level lists.
- Fixed an issue where the scroll position of the [[Map View]] wasn't correctly cached.

New since beta 4:
+ Added support for zooming on PDF views. // [PR 393](https://github.com/suchnsuch/Tangent/pull/393)
+ Added a setting for code tab size. Fixed an issue where code tab size was a non-integer value. // [Issue 396](https://github.com/suchnsuch/Tangent/issues/396)
- Fixed an issue where right-gutter elements could be misaligned. // [PR 394](https://github.com/suchnsuch/Tangent/pull/394)
- Fixed an issue where code blocks did not respond to panes resizing and did not shrink back down.
